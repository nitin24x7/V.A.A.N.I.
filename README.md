# V.A.A.N.I. stands for Voice Authetication and Acoustic Neural Interceptor

AI-powered real-time detection and prevention of voice-cloning impersonation attacks.

## Run locally

Prerequisites: Node.js 20 or newer, and npm.

```bash
cd /home/deepin/Vaani
npm install
npm run dev
```

Open the URL Vite prints (typically `http://localhost:5173`).

Production build:

```bash
npm run build
npm run preview
```

## Quick Start & Workflow Flow

1. Open **Dashboard** and click **Run full security sequence**, or walk the steps manually.
2. **Voice Enrollment** — capture a 15s genuine sample.
3. **Live Call** / **Command Center** — start intercept, then inject cloned audio.
4. **Banking Portal** — Approve Transfer locks on CRITICAL risk.
5. **SIEM Incidents** — intercept events appear without storing raw audio.
